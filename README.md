### 👨‍💻 Executive Summary & About Me

I am a **Full-Stack Software Engineer** focused on building resilient backends, high-concurrency architectures, and clean reactive user interfaces. With extensive production experience in **Laravel**, **PHP 8.3+**, and **Python**, alongside modern reactive frontends (**Vue 3**, **Inertia.js v2**, **TypeScript**), I specialize in turning complex requirements into production-ready software.

- 🔭 **Backend & Architecture:** High-throughput RESTful APIs, Clean Architecture, pessimistic row locks (`lockForUpdate`), zero race-conditions, and real-time WebSockets.
- 🎨 **Modern Frontend:** Reactive state handling with Vue 3 Composition API, type-safe TypeScript, and tailored Tailwind CSS.
- 🧩 **CMS & Custom Extensions:** Custom WordPress theme and plugin development adhering strictly to security standards.
- 🛡️ **Intranet & Security Standards:** Zero-CDN architecture design, offline-ready assets, cryptographic signers (`Ed25519`, `SHA-256`), and comprehensive automated testing.
